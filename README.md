# vibe-fit

Vibe Fit is a single `index.html`: workouts, deadlift, walking, calories, a daily
leaderboard and a competition chat, shared by every phone through Supabase
(project "Kemo Fit Project").

- `index.html`: the whole site. Open it from any static host (GitHub Pages works).
- `supabase/schema.sql`: tables, Row Level Security and Realtime (already applied).
- `supabase/functions/vf-register/`: the sign-up function (already deployed).

The account named "Kemo Fit" is the admin (table `vf_admins`).
